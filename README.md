# Logic Quest — O Laboratório de Circuitos

Jogo educativo de circuitos lógicos para navegador, em desenvolvimento conforme `PLANO_CODEX_LOGIC_QUEST.md`.

## Executar

Pré-requisitos: Node.js 22.12+ (recomendado LTS 24) e npm.

```bash
npm ci
npm run dev
```

Abra o endereço mostrado pelo Vite (normalmente http://localhost:5173).

```bash
npm run typecheck
npm run lint
npm test
npm run build
npm run preview
```

O build fica em `dist/`. Não é necessário backend nem serviços externos em execução.

- [x] Menu, seleção e acesso à primeira fase.
- [x] Adicionar, mover, conectar e remover portas.

- [x] README, requisitos e documentação correspondem à implementação.
- [x] Histórico com commits reais, semânticos, pequenos por etapa e com emojis.
- [x] Slides HTML locais e roteiro de 23 minutos preparados.

# Escopo e aceite — Logic Quest

## Diagnóstico inicial (etapa 0)

Repositório novo: README de uma linha, commit inicial e planejamento fornecido pelo usuário. Não há código, dependências, scripts, AGENTS.md aplicável ou modelo acadêmico `.docx`. O planejamento original será preservado sem alterações. Branch de trabalho: `feat/logic-quest`.

## Produto

Jogo educativo local para navegador: restaurar seis sistemas do laboratório montando circuitos combinacionais. Entradas e saída são fixas; portas podem ser adicionadas, deslocadas, conectadas e removidas. Cada handle de entrada recebe um fio; saídas permitem ramificação. As fases são dados, separados do motor e da interface.

## Aceite

- Menu, seleção, editor e sucesso; seis fases na ordem do planejamento.
- AND, OR, NOT e XOR corretas; sinais 0/1 visíveis; erros e ciclos tratados.
- Aprovação apenas após verificar todas as combinações da tabela-verdade; aceitar equivalência lógica dentro das restrições da fase.
- Progresso local versionado, recuperação segura e reinícios distintos.
- Execução sem serviços externos após instalar dependências; controles legíveis e foco visível.
- TypeScript, lint, testes e build executados; README, requisitos, decisões, evidências e slides coerentes.

## Dependências e execução planejadas

Vite, React, TypeScript, XYFlow, Tailwind, Lucide, componente Button do shadcn/ui e Vitest. Sem backend, login, ranking, multiplayer, editor de fases ou componentes com memória. Scripts previstos: `dev`, `typecheck`, `lint`, `test`, `build`, `preview`.
